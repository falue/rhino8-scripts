# Weave

1. Fusion export STEP  
2. Rhino import STEP (default options)
3. Run weave script
4. Rhino export STL, tolerance 0.05 mm  
5. Fusion import STL
    - "upload" to project, wait hundreds of seconds
    - "insert into current design"
    - right click on component: "break link"
    - scale to 10% for some reason
6. Fusion final export STL to 3d printer
